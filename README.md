## How to use

### Requirements

- Python 3.14 or above (recommended)
- `pipx` installer (Read [this gist] to learn how to install it)

### Installation

```shell
pipx install git+https://github.com/TheGittyPerson/template-repo.git
```

### Usage

To run:

```shell
template
```

### Uninstall

```shell
pipx uninstall template
```
